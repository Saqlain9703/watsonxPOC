# Governance

The deployment and native watsonx.governance integration procedure is documented
in [`docs/deploy-governance-native-ui.md`](../docs/deploy-governance-native-ui.md).
The deterministic bad-tool scenarios and expected evidence are documented in
[`fault-injection.md`](fault-injection.md).

Monitoring is tenant state applied by API after agents are imported; it is not an
agent YAML field. The current repository contains credential placeholders, so no
claim is made that remote monitoring or Governance association is already active.
